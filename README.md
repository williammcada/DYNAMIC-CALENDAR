# Dynamic Calendar

**A WILLIAM MCADA PRODUCT**

Dynamic Calendar is an offline, standalone HTML replacement for a fragile Excel lesson schedule, designed to generate and maintain a dynamic teaching calendar while preserving local control of the schedule.

## Canonical project record

**Repository:** `williammcada/Dynamic-Calendar`  
**Current state:** v1 standalone/offline HTML application with local scheduling, editing, backup/export, and print/PDF capabilities.  
**Handbook:** `williammcada/mcada-project-handbook`

The repository is the canonical home for the current source, permanent project brief, and approved version-specific change specifications. Chat history is working context rather than the permanent project record.
