# Dynamic Calendar v1 — Offline Calendar

**Status:** Current accepted functionality record; exact local source file requires confirmation.

## Requirements

Maintain a standalone offline HTML calendar with editable lesson sequence, dates, and events; local autosave; JSON backup/restore; CSV export; print/PDF; and distinct **Holidays** versus **No-Lesson Days**. Both date categories require bulk import and Remove all controls. Skipped days should display normally.
